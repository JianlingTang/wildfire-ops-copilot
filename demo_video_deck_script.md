# Wildfire Ops Copilot - 3 Minute Demo Video Deck

## Goal

Show why wildfire ops need an AI workflow, then demo how Wildfire Ops Copilot turns live hotspot, weather, warning, spatial, and Elastic MCP evidence into reports, scenarios, and approval-gated advisories.

## Timeline

| Time | Slide | Voiceover |
| --- | --- | --- |
| 0:00-0:15 | Opening hook | Wildfire response is a real-time intelligence problem. Australia and California both show the scale. |
| 0:15-0:35 | Climate pressure | Hotter, drier, windier conditions shrink the response window. |
| 0:35-0:55 | Operations gap | Evidence is scattered across hotspots, weather, warnings, maps, assets, SOPs, and public messaging rules. |
| 0:55-1:12 | AI bridge | The agent gathers evidence, keeps context, explains risk, and routes each request to the right workflow. |
| 1:12-1:28 | Project goal | Wildfire Ops Copilot helps operators monitor wildfire activity, analyze an AOI, and prepare approval-safe actions. |
| 1:28-1:52 | Top features | Live AOI focus, agent analysis with risk scoring, what-if scenarios, and public advisory drafts. |
| 1:52-2:08 | Tech stack | Firebase frontend, Cloud Run backend, Vertex AI Gemini through ADK, Firestore, and Elastic MCP. |
| 2:08-2:24 | Why Elastic MCP | The agent needs trusted operational memory: SOPs, incidents, warning guidance, templates, and reliability notes. |
| 2:24-2:53 | Live demo | Focus an AOI, ask for today's report, inspect trace and risk score, test a scenario, then draft an advisory for approval. |
| 2:53-3:00 | Closing | Turn scattered emergency data into explainable, approval-safe operational intelligence. |
